## 🚀 About the Project

**Abacus2k24** serves as the digital hub for the Abacus Coding Club. Designed and engineered by the 2K24 batch, this platform acts as a central ecosystem for club members to share knowledge, track events, participate in coding challenges, and showcase their technical innovations.

### Key Features
*   **Event Tracker:** Keep up with upcoming hackathons, coding workshops, and club meetups.
*   **Member Directory:** Profiles showcasing skills, GitHub links, and achievements of the 2K24 community.
*   **Learning Hub:** Curated resources, roadmaps, and tutorials for peer-to-peer learning.
*   **Leaderboards:** Friendly competitive tracking for club-specific coding contests.

## 📦 Getting Started

Follow these simple steps to set up a local copy of the project on your machine.

### Prerequisites
Make sure you have Git and Node.js installed.
```bash
node -v
git --version
```

### Installation & Local Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the Directory:**
   ```bash
   cd Abacus2k24
   ```

3. **Install Dependencies:**
   ```bash
   npm install
   ```

4. **Start the Development Server:**
   ```bash
   npm start
   ```
   Open `http://localhost:3000` (or your local port) in your web browser to view the application.
